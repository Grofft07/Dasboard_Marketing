Integrasi Sheet

Hubungkan ke Google Sheet via Apps Script — sama seperti Dashboard Advertiser
Integrasi Spreadsheet (Google Apps Script)
Data Toko, Input Harian & OKR tersinkron otomatis ke Google Sheets, bisa diakses dari device manapun.
ℹ️Auto-Sync Aktif: setiap dashboard dibuka, data terbaru otomatis ditarik dari spreadsheet (asal URL sudah diisi).
⚠️Penyebab paling sering data "hilang": setelah mengubah/tempel ulang kode Apps Script, URL lama TIDAK otomatis terupdate. Harus lewat Deploy → Manage deployments → ikon pensil (Edit) → Version: New version → Deploy, bukan bikin deployment baru (nanti URL-nya beda lagi). Selalu klik tombol Tes Koneksi di atas setelah deploy untuk memastikan benar-benar tersambung.
Buka Google Sheet → Extensions → Apps Script → tempel kode dari tombol "Lihat Kode Apps Script" → Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone) → salin URL ke kolom di atas. Sheet dengan nama yang benar akan dibuat otomatis saat data pertama kali tersimpan, tapi supaya rapi sejak awal, buat 6 sheet berikut manual: Toko (kolom: id, platform, nama, username, status, ppncpas — ppncpas diisi angka persen PPN CPAS toko itu, mis. 4 untuk 4%), Input (kolom: tanggal, tokoId, omzet, spending — nilai spending sudah termasuk PPN 11%), Target (kolom: tokoId, bulan, targetomzet, targetspending, targetroas — target bulanan toko, format bulan "2026-08", targetspending sudah termasuk PPN 11%), Affiliate (kolom: tanggal, tokoId, omzet, komisi, sampel — data affiliate specialist harian), TargetAffiliate (kolom: tokoId, bulan, targetomzetafiliasi, targetkomisi, targetsampel — target affiliate bulanan), dan OKR (kolom: periode, objId, objTitle, objOwner, krId, krText, krTarget, krCurrent, krUnit, krDirection, initId, initText, initDone, initDeadline, reflSoWhat, reflNowWhat — 1 baris per Initiative, jadi kolom-kolomnya "menyesuaikan" isi OKR: Objective dengan 3 Key Result & masing-masing 2 Initiative otomatis jadi 6 baris, dengan objTitle/krText diulang di tiap barisnya; kalau sheet OKR-mu masih format lama (cuma kolom periode+data), akan otomatis dimigrasikan ke format ini saat pertama kali disinkron ulang) — otomatis terisi setiap kamu menambah toko, input harian, input affiliate, atur target, atau mengubah OKR.
