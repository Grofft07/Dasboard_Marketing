⚙️ Pengaturan & Integrasi Google Sheet

Tempel URL Web App Apps Script dari Google Sheet kamu di sini supaya tugas tersinkron dua arah.
📄 Kode Backend (Code.gs)
Belum punya Web App? Buat Google Sheet baru → Extensions → Apps Script → hapus isi default → tempel kode di bawah → Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone) → salin URL-nya ke kolom di atas. Sheet "ToDo" (tugas harian) dan "Evaluasi Mingguan" (catatan bebas per tanggal) akan dibuat otomatis, dua-duanya di spreadsheet yang sama.
