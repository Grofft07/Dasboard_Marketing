Integrasi Spreadsheet (Google Apps Script)
Data Toko & Input Harian tersinkron otomatis ke Google Sheets, bisa diakses dari device manapun.
ℹ️Auto-Sync Aktif: setiap dashboard dibuka, data terbaru otomatis ditarik dari spreadsheet (asal URL sudah diisi).
Buka Google Sheet → Extensions → Apps Script → tempel kode dari tombol "Lihat Kode Apps Script" → Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone) → salin URL ke kolom di atas. Buat 5 sheet: Toko (kolom: id, platform, nama, username, status), Input (kolom: tanggal, tokoId, omzet, spending — nilai spending sudah termasuk PPN 11%), Target (kolom: tokoId, bulan, targetomzet, targetspending, targetroas — target bulanan toko, format bulan "2026-08", targetspending sudah termasuk PPN 11%), Affiliate (kolom: tanggal, tokoId, omzet, komisi, sampel — data affiliate specialist harian), dan TargetAffiliate (kolom: tokoId, bulan, targetomzetafiliasi, targetkomisi, targetsampel — target affiliate bulanan) — otomatis terisi setiap kamu menambah toko, input harian, input affiliate, atau atur target.
