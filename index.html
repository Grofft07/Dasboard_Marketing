Integrasi Sheet

Hubungkan ke Google Sheet via Apps Script — sama seperti Dashboard Advertiser
Integrasi Spreadsheet (Google Apps Script)
Data Toko, Input Harian tersinkron otomatis ke Google Sheets, bisa diakses dari device manapun.
ℹ️Auto-Sync Aktif: setiap dashboard dibuka, data terbaru otomatis ditarik dari spreadsheet (asal URL sudah diisi).
⚠️Penyebab paling sering data "hilang": setelah mengubah/tempel ulang kode Apps Script, URL lama TIDAK otomatis terupdate. Harus lewat Deploy → Manage deployments → ikon pensil (Edit) → Version: New version → Deploy, bukan bikin deployment baru (nanti URL-nya beda lagi). Selalu klik tombol Tes Koneksi di atas setelah deploy untuk memastikan benar-benar tersambung.
Buka Google Sheet → Extensions → Apps Script → tempel kode dari tombol "Lihat Kode Apps Script" → Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone) → salin URL ke kolom di atas. Sheet dengan nama yang benar akan dibuat otomatis saat data pertama kali tersimpan, tapi supaya rapi sejak awal, buat 7 sheet berikut manual: Toko (kolom: id, platform, nama, username, status, ppncpas, pic, pichist, affpic, affpichist (affpic = nama Affiliate Specialist toko itu, affpichist = riwayat pergantiannya, diisi otomatis) — ppncpas diisi angka persen PPN CPAS toko itu, mis. 4 untuk 4%; pic = nama pemegang akun; pichist = riwayat pergantian PIC, diisi otomatis oleh dashboard), Input (kolom: tanggal, tokoId, omzet, spending — nilai spending sudah termasuk PPN 11%), Target (kolom: tokoId, bulan, targetomzet, targetspending, targetroas — target bulanan toko, format bulan "2026-08", targetspending sudah termasuk PPN 11%), Affiliate (kolom: tanggal, tokoId, omzet, komisi, sampel, hppSampel, hppTotal, sampelW100, sampelW200, sampelN30, sampelN60, gmvLive, gmvVideo, gmvProduk, gmvMedsos — data affiliate specialist harian; gmvLive/gmvVideo/gmvProduk dipakai toko TikTokShop, gmvLive/gmvVideo/gmvMedsos dipakai toko Shopee, omzet = total dari kolom breakdown yang relevan; kalau sheet Affiliate-mu masih format lama tanpa kolom breakdown, kolomnya akan otomatis ditambahkan saat pertama kali disinkron ulang), TargetAffiliate (kolom: tokoId, bulan, targetomzetafiliasi, targetkomisi, targetsampel — target affiliate bulanan), HostLive (kolom: tanggal, tokoId, host, jamMulai, jamSelesai, durasi, gmv, penonton, komentar — report sesi live host, 1 baris per sesi), TargetHostLive (kolom: host, bulan, targetjam, targetgmv, targetgmvjam — target live bulanan per orang/host). Semua sheet otomatis terisi setiap kamu menambah toko, input harian, input affiliate, host live, atau mengatur target.
